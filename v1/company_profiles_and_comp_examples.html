Reviewer categories2 = direct peer, same product and customers. 1 = adjacent, overlap in product or customers. 0 = not a peer. Counts are for the curated examples shown here, not all 293 reviewed pairs.

Each numeric facet score includes a quote from each company's website. The facet fills are shown for context only, so a facet can be n/a even when both fills exist.
Ranking numbersS = weighted similarity over facets with evidence. C = share of facet weight with evidence. Final rank = agent grade, then S, among the comps the reviewer labeled. B3 rank = position in our embedding + keyword baseline's top 10.
Facets: Claude Sonnet fills from each company's saved website. Grades, facet scores and reasons: the agent loop (Sonnet), which can search the saved site or the web before it answers.
