    Browsing modes for business users
    • Create mode
      The default mode when you create a requisition and PunchOut to Bio-Rad. You can create and modify multiple shopping carts.
    • Edit mode
      Enables you to edit an existing requisition before submission. Only the cart you PunchedOut to can be modified; other carts will remain inaccessible.
    • Inspect mode
      When you PunchOut to Bio-Rad from an existing requisition and initiate an edit session, you will enter this mode. Cart contents cannot be modified in this state.
